# Put hand-downloaded images here

Drop each file into the right folder, then run `make sync DEST=...`.

```
images/windows/      Windows 11 ISO, Hiren's BootCD PE, Windows-To-Go .vhdx
images/rescue/       SystemRescue, GParted Live, Super Grub2
images/security/     Kali Linux live, Tails
images/misc/         FreeDOS
```
