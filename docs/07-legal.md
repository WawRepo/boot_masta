# Licences and the law

## Windows

Microsoft lets anyone download the Windows ISO. **Running** Windows needs a
licence key. That is true for a normal install and for Windows-To-Go alike.
This repo downloads nothing from Microsoft and gives you no key.

## Linux

Ubuntu, Debian, Arch, Kali and the rescue discs are free to download, copy
and hand to a friend. Each has its own licence inside the ISO.

## Kali Linux and the security tools

Kali holds tools that break into computers. Using them on a machine you do
not own, without written permission, is a crime in most countries.

Fine: your own laptop, a lab you built, a client who signed a test agreement.
Not fine: the café wifi, your neighbour, your employer without a signed scope.

## ShredOS and disk erase

ShredOS destroys data. There is no undo, no recycle bin, no recovery shop
that can help. Read the drive name out loud before you press Enter.
